# Road Accident Data Analysis (2021–2022)

## Motivation

Road accidents remain a major public safety concern in India, yet most discussions around them rely on high-level statistics without much exploratory analysis. While working on this project, I wanted to understand how publicly available accident data could be explored to identify patterns and trends that are not immediately obvious from raw tables.

This project was built to apply basic data analysis and visualization techniques to a real-world dataset and extract insights in a clear and interpretable manner.

---

## Problem Statement

Public road accident datasets often contain large volumes of information but are not directly useful without structured analysis.

The challenges addressed in this project include:

* understanding state-wise accident distributions
* comparing accident data across different years
* visualizing accident-related metrics to highlight trends

The goal of this project is descriptive analysis rather than prediction or automation.

---

## Project Overview

This project performs exploratory data analysis on road accident data in India for the years 2021 and 2022. Using Python and standard data analysis libraries, the dataset is cleaned, processed, and visualized to better understand accident trends across different states.

The focus is on summarizing the data, identifying visible patterns, and presenting insights through plots and charts rather than building predictive or machine learning models.

---

## Dataset

The dataset used in this project is sourced from publicly available government data related to road accidents in India. It contains state-level accident statistics and related attributes for the years 2021 and 2022.

The dataset is used strictly for academic and analytical purposes.

---

## What This Project Does

* Cleans and preprocesses raw road accident data
* Performs exploratory data analysis (EDA)
* Generates visualizations to compare accident trends
* Summarizes observations derived from the data

The emphasis is on understanding the dataset rather than optimizing outcomes.

---

## What This Project Does Not Do

To keep the scope clear, this project:

* does not build predictive or machine learning models
* does not perform real-time accident detection
* does not attempt causal inference
* does not provide policy recommendations

All results are descriptive in nature.

---

## Tools and Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

These tools were chosen for simplicity and interpretability.

---

## Results and Observations

The analysis highlights differences in accident counts across states and between the two years considered. Some regions consistently report higher accident numbers, while others show noticeable changes over time.

These observations are intended to provide an initial analytical view rather than definitive conclusions.

---

## Academic Context and Recognition

This project was developed as part of a university-level competition and received recognition for its analysis and presentation. The work was evaluated in an academic setting with emphasis on clarity, correctness, and interpretation of data.

---

## Limitations

* The analysis depends entirely on the quality and granularity of the available dataset
* Only two years of data are considered
* External factors such as population, vehicle density, or road infrastructure are not modeled

The insights should be interpreted within these limitations.
